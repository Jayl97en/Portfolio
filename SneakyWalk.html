Sneaky Walk

This animation represents the sneaky movements of a character in the Sneaky Slumbers project. The animation was done in Blender, with the asset being taken from Joey Carlino's 'Simple Character Rig for Blender'. The animations were done by myself and represent the 3 states that the character can be in in the game. The first one is the sneaky walk, the main movement that the character will use. The second one is the crouch, which slows the players movement, but allows them to be more stealthy. The last one is the sleepwalk animation, which the character uses to get past enemies without being detected.
